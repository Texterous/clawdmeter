Networks

The device joins the strongest saved network it can see. Up to four, tried in order. Leave a password blank to keep the one already stored.

Identity

Reachable as clawdmeter.local on most networks. Changing it reboots the device.

Setup hotspot

Shown when no saved network is in range. This is how you get back in after moving the device to a new place, so leaving it open is usually right.

Eight characters minimum, or blank for an open hotspot.

Brightness

Not every unit has the sensor populated. If the screen does not react to covering it, leave this off.

Night dimming

POSIX TZ rule. Amsterdam is CET-1CEST,M3.5.0,M10.5.0/3. Night dimming stays off until the clock has actually been confirmed by NTP, so a device with no time never blanks by accident.

Panel

If red and blue look swapped, force the other one. Panels vary between units of the same model.
On this board it is. Unticking it makes the screen dark at 100%.

Push endpoint

Anything that can POST JSON can drive the screen. No credentials needed — this endpoint only writes the numbers being displayed.

Options

Leave empty for the normal push setup. Fill it in only if you want the device to fetch instead. Must be plain http:// — this build has no TLS, which is what keeps it small enough to install on a factory-fresh unit.

Firmware

Running—

Upload an image

Any ESP8266 image that fits: a Clawdmeter build, upstream smalltv-mod, ESPHome, Tasmota, or GeekMagic's stock firmware. It is your device.

Two checks run before anything is written — the image has to fit, and it has to look like an ESP8266 image at all. This board has no USB recovery mode, so a wrong file would otherwise mean opening the case. See flashing something else.

Settings

The backup contains your WiFi passwords in clear — same trust level as typing them into this page.

Access

Digest auth, so the password is not sent in clear over plain HTTP. The usage push endpoint stays open — the agent has no way to carry credentials, and it can only change what the screen shows.

Power

A factory reset wipes saved settings, including WiFi, and comes back up on the setup hotspot. The firmware is untouched.
