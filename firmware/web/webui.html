Step 1 of 2

You are setting up this device. Check the device screen — it shows the same name under Join this WiFi. If it does not, you have joined someone else's device: go back to your WiFi settings and pick the matching one.

Then choose your own network below and save. The device restarts, joins it, and shows you where to go next on its own screen.

Networks

The device joins the strongest saved network it can see. Up to four, tried in order. Leave a password blank to keep the one already stored.

Identity

Reachable as clawd.local on most networks. Changing it reboots the device. Capped at 32: past that the address stops fitting the device screen and is dropped from it.

Setup hotspot

Shown when no saved network is in range. This is how you get back in after moving the device to a new place, so leaving it open is usually right.

Eight characters minimum, or blank for an open hotspot. The name is capped at 32: longer or empty, and the radio refuses to start the hotspot at all — which is the only way back into a device that cannot reach your network.

Brightness

Not every unit has the sensor populated. If the screen does not react to covering it, leave this off.

Night dimming

POSIX TZ rule. Amsterdam is CET-1CEST,M3.5.0,M10.5.0/3. Night dimming stays off until the clock has actually been confirmed by NTP, so a device with no time never blanks by accident.

Panel

If red and blue look swapped, force the other one. Panels vary between units of the same model.
On this board it is. Unticking it makes the screen dark at 100%.
White balance, for matching a batch of units to each other.

Start here

This device shows how much of your Claude Code usage you have spent. It cannot read that by itself: one small program on your computer reads it and sends it here. Five steps, about five minutes. You need a laptop or desktop — a phone cannot run it.

Do the Wifi tab first. The address in step 5 is the name this device will have once it joins your network, not the one it answers to now.

  1. Install Python 3.10 or newer from python.org/downloads. On Windows, tick Add python.exe to PATH in the installer.
  2. Download the sender from github.com/giovi321/clawdmeter-daemon: green Code button, Download ZIP, then unzip it.
  3. In the unzipped folder run .\install.bat (Windows) or ./install.sh (macOS, Linux). It builds its own private environment and cannot disturb anything else on your machine.
  4. Let it read your usage: run claude setup-token, copy the sk-ant-oat… value it prints, and store it as CLAUDE_CODE_OAUTH_TOKEN. On Windows, open a new terminal afterwards or it will not be set yet.
  5. Start it, pointed at this device — the address is already filled in.
    These run it in the background with an icon in your system tray or menu bar — that icon is how you check on it and quit it. Numbers appear here and on the device within about twenty seconds.

Note. Another device on this network already answers to this unit's name, so the commands above use its IP address instead. If the address changes later, come back here for the new one.

Push endpoint

Anything that can POST JSON can drive the screen. No credentials needed — this endpoint only writes the numbers being displayed.

s/w are the 5-hour and 7-day percentages, sr/wr the minutes until each resets, st the status string.

Options

The session board lists every Claude session running on your machine and what each one is doing — working, waiting for you, or stuck on a permission prompt. It needs a daemon new enough to send them.
Usage meters only; the session board ignores it. The mascot appears when nothing has arrived for a while — your laptop asleep, usually. Off keeps the last numbers up instead, headed STALE so an old reading cannot pass for a live one. Leave empty for the normal push setup. Fill it in only if you want the device to fetch instead. Must be plain http:// — this build has no TLS, which is what keeps it small enough to install on a factory-fresh unit.

Firmware

Running—

Upload an image

Any ESP8266 image that fits: a Clawdmeter build, upstream smalltv-mod, ESPHome, Tasmota, or GeekMagic's stock firmware. It is your device.

Two checks run before anything is written — the image has to fit, and it has to look like an ESP8266 image at all. This board has no USB recovery mode, so a wrong file would otherwise mean opening the case. See flashing something else.

Settings

The backup includes your WiFi passwords only when this page is password-protected (System → Access). Without that they are left out: it restores every other setting, but a password it does not carry can only be re-filled while this device still holds it — not after a factory reset, and never onto another unit.

Access

Digest auth, so the password is not sent in clear over plain HTTP. The usage push endpoint stays open — the agent has no way to carry credentials, and it can only change what the screen shows.

Power

A factory reset wipes saved settings, including WiFi, and comes back up on the setup hotspot. The firmware is untouched.
